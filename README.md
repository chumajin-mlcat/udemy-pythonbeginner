## プログラミング初心者でも「とにかくやってみる」から始めよう！

この講義は自己紹介の前 に、まずは Google Chromeがあれば動かせちゃう環境で動かすところからスタートします。それほど「実際にやってみる」ことを重視しているコースです。※ 企業様の規制など社内でGoogle Colabが使用できない/禁止されている場合は、文末の「注意事項」をご確認ください。

## 世界最大のAIコンペコミュニティKaggleで2冠を獲得したグランドマスターによる超初心者向けPython入門

このコースは、Kaggleで2冠のグランドマスター(AIコンペで、2023年は100万以上の賞金を得ました)が、製造業で15年以上エンジニアとして培ったノウハウを余すところなく伝授する 超初心者向け のPython入門講座です。
